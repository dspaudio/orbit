# ORBIT 0.4.1

## 변경 사항

- 오리지널 OP-1의 Synth / Drum / Event Tape / Mixer와 T1 engine / T2 envelope / T3 effect / T4 LFO를 실제 FM-1 조작과 웹 편집 경로에 반영했습니다. 기본 encoder 색은 blue / green / white / orange입니다.
- 믹서의 KNOB 1–4는 네 트랙 LEVEL 또는 PAN을 조절합니다. SELECT로 기존 선택 트랙의 SWING / LEVEL / LEN / PAN 편집에도 접근합니다.
- Orbit 워드마크·부트 화면, 영어 웹 기본 언어, preview 입력·stereo visualizer tap, 중단된 editor restore 복구를 반영했습니다.
- PHASE resonance 창 계산과 overload voice 검색을 줄여 기존 호스트 CPU·ALNK0 정적 예산 실패를 해결했습니다. golden·예산 기준과 허용치는 바꾸지 않았습니다.
- 웹 에뮬레이터는 같은 C 펌웨어를 새로 빌드하며 SLOOP와 Felucca 비교 바이너리를 보존합니다.

## 설치와 호환성

첨부된 `orbit.fwsc`를 내려받고 `SHA256SUMS`로 확인합니다. 설치 identity는 기존 `FM-1_900`, 펌웨어 버전은 `ORBIT 0.4.1`입니다.

```sh
python3 tools/fm1_install.py orbit.fwsc
```

FUN5 저장 형식, 이전 FUN1–FUN4 읽기 경로, ORBIT engine ID와 editor protocol v9를 유지합니다. FUN5는 ORBIT 0.3 / SLOOP 2.3으로 내릴 때 읽을 수 없으므로 먼저 백업합니다.

[웹 에뮬레이터](https://dspaudio.github.io/orbit-web-emu/)는 실제 C 엔진을 실행하며 프로젝트·설정은 브라우저 IndexedDB에 보관합니다. Event Tape는 sequencer 이벤트 편집이며 PCM 녹음이 아닙니다. 에뮬레이터의 USB·SysEx·샘플 업로드와 Bluetooth는 지원하지 않습니다.

## 검증 범위

pi32v2 빌드·메모리·정적 예산, Linux 19개 호스트 프로그램과 전체 러너, 새 macOS instruction-counted golden/CPU 검사, 최신 native HTTP/PCM 및 실제 패키지 형식 검사를 통과했습니다. `orbit.fwsc`는 610,019 B이며 SHA-256은 `31afad04333e6593e0333039c53f26b53ccab032b665cdc8e4aa3ec82bb53253`입니다. 기존 독자 엔진 12개 preset의 golden·CPU baseline 부재는 유지합니다.

실행 결과는 [검증 기록](../VALIDATION.md)에 기록합니다. FM-1 실기기는 연결하지 않았으므로 플래싱·부트·USB 전송·IRQ 사이클·오디오 underrun·지연은 미검증입니다. 타깃 빌드와 브라우저 실행 통과를 실기기 안정성 확인으로 해석하지 않습니다.
