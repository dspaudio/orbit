# ORBIT 0.9.B — Bluetooth MIDI sound variant

Download **orbit-ble.fwsc** for the M-VAVE FM-1. This is the separate
Bluetooth MIDI variant of [ORBIT 0.9.0](0.9.0.md), not a replacement for
the default sample-based build. Both use the `FM-1_900` installation identity.

- Turn the radio on with **MENU > SYSTEM > BLUETOOTH**. It starts off
  after reboot and advertises as **ORBIT FM-1**.
- To follow an external BLE MIDI clock, choose **GLO > SYSTEM > SYNC = USB**;
  BLE input shares the USB clock-input route.
- Hold **ENV + LFO for 2 seconds** for controller mode. Keys send notes,
  knobs send assignable CCs, and the sequencer keeps playing.
- Melodic built-in samples become same-named FM voices. The original PERC
  drum samples and user-sample playback remain available. See the
  [complete sound list](../../README.md#sounds-replaced-in-the-bluetooth-build).
- The delay line is shorter: about 0.74 seconds, or 0.37 seconds per side
  in PING mode.
- Writes to FM6/USR4 sectors containing stock radio calibration are refused.
  Radio startup needs valid original calibration or its retained device-local copy.
- MIDI clock generation and outgoing SysEx over BLE are not implemented.

The installed device reported **FELUCCA ORBIT 0.9.B**. The device owner
confirmed BLE pairing and external-clock synchronization. Hardware timing,
worst-case radio/audio load and stack high-water remain unmeasured.
The default SAMPLE/GRAIN static-cost baselines are exceeded by this variant;
the measured values and host checks are recorded in
[VALIDATION](../VALIDATION.md#orbit-090-and-09b-candidates-2026-10-30).

Compare the two sound builds in the
[web emulator](https://dspaudio.github.io/orbit-web-emu/).
Browser audio uses the firmware C engine, not a JavaScript approximation.
The browser does not emulate Bluetooth.

Bluetooth integration is ported from Hortator `4e40f27` by DEADACTIVE,
with felucca-ble/Felucca credits and SHA-256-pinned JieLi SDK inputs.
See [LICENSING](../../LICENSING.md). The SLOOP 2.8.4 fixes and unchanged
ORP8/OPB3 storage contracts are described in the [shared notes](0.9.0.md).
