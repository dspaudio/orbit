# ORBIT 1.0.0 and 1.0.B

ORBIT 1.0 adds four chord voicings, keeps arpeggios moving across chord changes, and makes its MIDI controller easier to use with a DAW. Both FM-1 builds keep the `FM-1_900` install identity.

| Build | Package | Sound |
| --- | --- | --- |
| 1.0.0 | `orbit.fwsc` | Original melodic and drum samples |
| 1.0.B | `orbit-ble.fwsc` | FM replacements for built-in melodic samples; original drums |

The Bluetooth build also accepts phone audio. Read the [1.0.B notes](https://github.com/dspaudio/orbit/blob/v1.0.B/docs/releases/1.0.B.md) for pairing, mixing and its shorter delay.

## Chords and arpeggios

The CHORD setting adds **OPEN** (root, fifth and tenth), **OPEN7**, **ADD9** and **6TH** alongside the existing modes. The open voicings put the third an octave up. Chord modifiers and voice leading still apply.

When you release one chord and play the next within an arpeggiator step, the arpeggio keeps its rhythmic phase instead of restarting from its first note. Shared notes remain held across the change.

## MIDI controller feedback and switches

The controller screen follows incoming CC values on its controller channel: a DAW moving an assigned knob CC updates its displayed value, and feedback to a toggle switch updates its lit state. **EDIT + FX / SEL / ENV / LFO** selects momentary or toggle operation for each switch; the choice is saved in device settings. Toggle switches stay on after release and turn off on the next press. Previous settings default to momentary switches.

The existing **OCT- + OCT+** tap enters or leaves controller mode. MIDI notes and CCs still leave over USB, and over Bluetooth MIDI when connected in 1.0.B.

## Compatibility and validation

ORP8 projects, OPB3 user banks and the `step_t` format are unchanged. The controller switch modes use reserved bytes in the existing device settings; the Bluetooth build extends its own radio-settings object to keep phone pairing keys while reading older objects.

The device owner reports that the current firmware works on the FM-1. Host and target checks, package hashes and any remaining measurement limits are recorded in the [validation record](https://github.com/dspaudio/orbit/blob/v1.0.0/docs/VALIDATION.md).
