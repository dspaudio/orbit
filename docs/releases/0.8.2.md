# ORBIT 0.8.2

**Stereo delay types and about 19 KB of static RAM back.**

This release adds a stereo **TYPE** to the shared delay, removes the
full-screen visualizer and ports SLOOP 2.7 memory changes, with credit and
thanks to the SLOOP authors and to Andre Rezemini, whose sloop-lab RAM branch
they come from (SLOOP 2.7, `ba54ba5`).

The default FM-1 package was installed on **2026-10-29**: write 100%, restart
and `FM-1_900` identity. The device owner confirmed normal operation and the
three delay types by ear and approved release.
Official firmware assets are **FM-1 only**: `orbit.fwsc` and `SHA256SUMS`.
[Product introduction](../../README.md) · [User guide](../../GUIDE.md)

## Stereo delay

**FX > DLY 2 > TYPE** chooses how the shared delay comes back:

- **MONO:** the original centred echo. It is the default, and projects from
  earlier versions open with it.
- **WIDE:** the left echo at the delay time, the right one 13 ms later.
- **PING:** echoes alternate left and right, each bounce lowered by FDBK.
  PING splits the existing delay line in two, so its longest time is 0.74 s;
  longer TIME settings are held at that length.

Changing TYPE silences the delay for about 25 ms while the line is cleared,
so no stale echo jumps sides. TYPE uses no extra delay memory. It is saved in
spare bits of the project and its song sections, so the **ORP8** format is
unchanged; earlier firmware ignores those bits. The web editor shows
**DLY 2** when connected to 0.8.2.

## Memory

| Resource | 0.8.1 | 0.8.2 |
| --- | --- | --- |
| Static RAM `.data + .bss` | 97,544 / 98,304 B (760 B free) | 78,584 / 98,304 B (19,720 B free) |
| Pool | 333,948 / 344,064 B | 328,444 / 344,064 B |
| App image | 566,360 B | 557,192 B |

- **Visualizer removed.** HOME on Tape now stays on Tape. Pages that draw
  the output oscilloscope still do.
- **USER preset banks** are read in place from flash instead of a RAM copy.
  At the first start, a bank still stored as OPB2 or UPB1 is converted and
  written back once as **OPB3**, keeping every sound value and macro
  assignment. An editor restore converts a bank in place.
- **DRAWBAR** keeps its state in the shared engine arena. After GRAIN, FM6,
  PHYS, CLUSTER or CLOUD on the same part, its wheels restart their phases.
- MIDI note routing and two short-lived buffers share memory as in SLOOP 2.7.

Static RAM headroom is not total runtime free RAM: POOL and the stacks are
separate, and stack high-water usage is unmeasured.

## Storage and build

**ORP8 projects and OPB3 USER banks are unchanged**, as are the `step_t`
layout and editor protocol 13. The editor protocol reports one more global
parameter (46).

Use the default FM-1 build:

```sh
PYTHON=~/.jieli/orbit-venv/bin/python sh build.sh
```

The source version is `ORBIT 0.8.2`; the install identity remains `FM-1_900`.

## Validation

The full host suite, native preview, web tests and pi32v2 target build and
budget checks passed. **All 218 audio renders match the goldens unchanged.**
New host tests cover the delay types, the TYPE's project round trip, the
USER bank read in place with its one-time conversion, and in-place bank
conversion. See the [validation record](../VALIDATION.md#orbit-082-release-package-2026-10-29).

Not tested: measured audio quality, hardware timing and underruns, flash
cache behaviour after a save measured on the device, and physical OCT-
power-on rescue.
