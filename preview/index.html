Orbit FM-1 · 0.4.0

A host preview running the actual C firmware display, sequencer and sound engines. Audio arrives in 250 ms chunks; this does not reproduce FM-1 hardware latency.

Press Start audio to play.

HOME = event Tape · EDIT = sound parameters · SEQ = steps · GLO = mixer
Tape: head / in / out / copy·lift → OCT− edits, OCT+ drops
Track selects a track. OCT± changes octave outside Tape. SELECT changes pages, tempo on Tape, or visualizer style.

Use the keys to play and record after starting audio. REC arms recording. Sample import, CHOP editing and device upload require a real FM-1 connected to web/editor.html. Preview project saves are nonpersistent test doubles. This preview supports button taps only; held-button menus and layer combinations require the hardware.
