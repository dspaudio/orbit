Other FM-1 keys

Synth = EDIT on the selected synth track · Drum = Track + to track 4, then EDIT (DRUMS; EDIT again toggles GRID / KIT) · Event Tape = HOME (on the Tape, HOME opens the visualizer) · Mixer = GLO on the Tape (elsewhere GLO opens the global pages)
Engine / Envelope / Effect / LFO = EDIT / ENV / FX / LFO: tapping again moves to the next real page. Highlights follow the actual firmware state returned by the C host; the sound-module row is unavailable on the drum track.
Tape: head / in / out / copy·lift → OCT− edits, OCT+ drops. Track selects a track. OCT± changes octave outside Tape. SELECT changes pages, tempo on Tape, or visualizer style.

Use the keys to play and record after starting audio. REC arms recording. Sample import, CHOP editing and device upload require a real FM-1 connected to web/editor.html. Preview project saves are nonpersistent test doubles. This preview supports button taps only; held-button menus and layer combinations require the hardware.
